# ReFoRCE — Text-to-SQL Agent

ReFoRCE(**Re**finement **f**or **C**orrect **E**xecution) is a text-to-SQL system from Snowflake Labs that generates accurate SQL queries via iterative self-refinement and majority voting.

> Source: [Snowflake-Labs/ReFoRCE](https://github.com/Snowflake-Labs/ReFoRCE)

---

## Architecture

```
Natural Language Question
    ↓
[format_answer]  ← LLM determines expected CSV output format
    ↓
[exploration]    ← LLM issues 10+ exploratory SQL queries to understand schema
    ↓
[self_refine]    ← LLM generates SQL → execute → check consistency → repeat (max 5)
    ↓              (self-correction on errors, self-consistency on results)
[vote_result]    ← (optional) Run N times, pick best result by majority vote
    ↓
result.csv + result.sql
```

### Key Mechanisms

| Mechanism | Description |
|---|---|
| **Exploration** | Issues 10 simple→complex SQL queries to understand column values before answering |
| **Self-correction** | When SQL errors occur, asks LLM to fix; propagates fix to similar SQLs |
| **Self-consistency** | Stops refining when the same result appears twice consecutively |
| **Schema linking** | Filters irrelevant tables before main inference (for large schemas) |
| **Majority voting** | Runs N independent instances, selects best answer via LLM comparison |

## Quick Start

### 1. Install dependencies

```bash
# Create Python 3.10 environment
conda create -n reforce python=3.10 -y
conda activate reforce

# Install core dependencies
pip install -r requirements.txt

# Optional: Snowflake support
pip install snowflake-connector-python

# Optional: BigQuery support
pip install google-cloud-bigquery
```

### 2. Configure credentials

```bash
# Copy env template
cp .env.example .env

# Set OpenAI API key
export OPENAI_API_KEY=sk-...

# For Azure OpenAI
export AZURE_ENDPOINT=https://your-resource.openai.azure.com/
export AZURE_OPENAI_KEY=your-key

# For Snowflake: create snowflake_credential.json
# For BigQuery: place bigquery_credential.json
```

### 3. Prepare data

Place your examples in the `examples/` directory. Each task has its own subfolder:

```
examples/
├── local_task1/          # SQLite task (prefix: local)
│   ├── database.sqlite
│   └── prompts.txt       # auto-generated by reconstruct_data.py
├── sf_task2/             # Snowflake task (prefix: sf)
│   └── ...
└── spider2-lite.jsonl    # Task definitions
```

### 4. Run

**SQLite (Spider2-lite):**
```bash
bash scripts/run_lite.sh gpt-4o 3 8
```

**Snowflake (Spider2-snow):**
```bash
bash scripts/run_snow.sh o1-preview 3 8
```

**Manual run:**
```bash
# Generate schema prompts first
python reconstruct_data.py --example_folder examples --add_description --add_sample_rows

# Run with voting
python run.py \
    --task lite \
    --db_path examples \
    --output_path output/my-run-log \
    --model gpt-4o \
    --pre_model gpt-4o \
    --model_vote \
    --num_votes 3 \
    --num_workers 4 \
    --max_iter 5
```

## Output Structure

```
output/my-run-log/
└── task_id/
    ├── result.csv       # Final answer
    ├── result.sql       # Final SQL query
    ├── log.log          # Detailed execution log
    ├── vote.log         # Voting decision log (if --model_vote)
    ├── 0result.csv      # Vote candidate 0 (if --model_vote)
    ├── 0result.sql
    └── ...
```

## Key Arguments

| Argument | Default | Description |
|---|---|---|
| `--task` | `snow` | `snow` for Snowflake, `lite` for SQLite |
| `--db_path` | `examples` | Path to examples directory |
| `--output_path` | `output/...` | Where to save results |
| `--model` | `o1-preview` | Main inference model |
| `--pre_model` | `o1-preview` | Exploration/correction model |
| `--max_iter` | `5` | Max self-refinement iterations |
| `--model_vote` | `False` | Enable majority voting |
| `--num_votes` | `3` | Number of voting candidates |
| `--num_workers` | `16` | Parallel worker threads |
| `--azure` | `False` | Use Azure OpenAI |
| `--schema_linking_model` | `None` | Enable schema linking with this model |
| `--rerun` | `False` | Rerun only empty results |

## File Overview

| File | Role |
|---|---|
| `agent.py` | Core `REFORCE` class: exploration, self-refine, voting, schema linking |
| `chat.py` | `GPTChat` wrapper for OpenAI / Azure OpenAI |
| `sql.py` | `SqlEnv` class: SQLite / Snowflake / BigQuery execution |
| `prompt.py` | `Prompts` class: all LLM prompt templates |
| `reconstruct_data.py` | Builds `prompts.txt` schema files from DDL/SQLite |
| `run.py` | Entry point: parallel task processing |
| `get_metadata.py` | Collects final CSV results for evaluation |
| `utils.py` | Shared utility functions |
